# Pot Images for Full Screen Menu

This folder should contain aesthetic pot images with transparent backgrounds (PNG format).

## Required Images:

Each menu tab displays **2 pot images** - one on the left and one on the right of the text.

### Work Tab (2 images):
1. **tree1.png** - Left pot for "Work"
2. **tree2.png** - Right pot for "Work"

### About Tab (2 images):
1. **pot1.png** - Left pot for "About"
2. **pot2.png** - Right pot for "About"

### Services Tab (2 images):
1. **service1.png** - Left pot for "Services"
2. **service2.png** - Right pot for "Services"

### Contact Tab (2 images):
1. **contact1.png** - Left pot for "Contact"
2. **contact2.png** - Right pot for "Contact"

**Total: 8 images**

## Image Requirements:

- Format: PNG with transparent background
- Size: Recommended 500x500px or larger
- Style: Aesthetic, modern potted plants/trees
- Background: Transparent (no background color)
- Variety: Each tab should have 2 different but complementary pot styles

## Where to Find Free Aesthetic Pot Images:

You can download free aesthetic pot images from these sites:

1. **CleanPNG** - https://www.cleanpng.com/ (search for "potted plant" or "plant pot")
2. **PNGTree** - https://pngtree.com/ (search for "aesthetic plant" or "potted plant")
3. **HiClipart** - https://www.hiclipart.com/ (search for "plant pot")
4. **Pikwizard** - https://pikwizard.com/ (search for "transparent plant pot")

## Recommended Image Sources:

- Search for "aesthetic potted plant png transparent"
- Look for images with clean, modern styling
- Ensure the pot/plant is centered and well-lit
- Images should have a transparent background for best results
- Mix different pot styles for visual variety within each tab

## Once Downloaded:

1. Save each image with the corresponding filename listed above
2. Place them in this `pots` folder
3. The full-screen menu will automatically display 2 pots per tab when you hover over menu items
4. Left pot will be positioned at bottom-left, right pot at bottom-right with floating animations
